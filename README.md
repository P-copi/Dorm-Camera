# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.16

V0.1.16 is the Video Playback + REC Polish build. It keeps the proven V0.1.15 camera layout and polished controls, removes the runtime VideoView resizing that could cause a black playback surface on some Samsung devices, centers playback using the VideoView's own aspect-aware measurement, keeps the display awake during playback, and replaces the long recording status sentence with a compact pulsing REC timer capsule while preserving the normal camera/GPS status chip.

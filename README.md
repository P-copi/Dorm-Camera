# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.14

V0.1.14 is the Camera Polish build. It keeps the proven V0.1.13 camera, video, GPS, folder and Explorer behavior, while refining the main camera controls with a more premium layered shutter, clearer active states for Flash/EV/video recording, more balanced control spacing, and matched left/right camera controls without changing the established layout or workflow.

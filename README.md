# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.23

V0.1.23 is the Smart Volume Shutter build. It keeps the proven V0.1.22 camera UI, selfie mirror, shutter sound control, 3x3 grid, storage guard, safe video finalization, branding and Explorer unchanged. Volume Up/Down now use a dual-action gesture: a short press changes normal media volume and shows the Android volume UI, while a long press uses the physical key as a one-shot photo shutter. During video recording the volume keys keep normal Android volume behavior and never trigger a still photo.

Stable baseline: branch `stable-v0.1.22` preserves the fully tested V0.1.22 release before the Smart Volume Shutter behavior was added.

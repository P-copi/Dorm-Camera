# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.22

V0.1.22 is the Camera Reliability & Pro Controls build. It keeps the proven V0.1.21 camera UI, selfie mirror, shutter sound control, branding, Explorer, centered video playback, REC indicator and save banners unchanged, while adding four reliability/pro features: physical Volume Up/Down shutter capture, a persistent professional 3x3 composition grid, free-storage checks before photo/video capture with a compact in-app warning banner, and safe video finalization when the camera activity is interrupted by screen-off, app switching or another foreground interruption.

Stable baseline: branch `stable-v0.1.21` preserves the fully tested V0.1.21 release before these new controls were added.

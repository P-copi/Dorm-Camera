# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.19

V0.1.19 is the Launcher Icon Fix build. It keeps all proven V0.1.18 camera, Explorer, splash and branding behavior unchanged, and moves the approved Dorm Camera gold/black by.P logo into standard Android launcher mipmap/adaptive-icon resources so Samsung One UI and modern Android launchers can display the installed app icon correctly. CI also verifies that the built APK advertises an application icon.

# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.15

V0.1.15 is the Compact Header + Video Center build. It keeps the proven V0.1.14 camera, video, GPS, folder and Explorer behavior, while making the camera header more compact to increase preview space, moving the camera/GPS status upward, switching dialogs and popup surfaces to a softer dark theme, polishing Preview controls, and fitting Explorer video playback to the center of the preview area while preserving the original video aspect ratio.

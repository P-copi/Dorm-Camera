# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.13

V0.1.13 is the Visual Polish build. It keeps the proven V0.1.12 camera, video, GPS, folder and Explorer behavior, while refining the camera into a more professional dark interface with a circular shutter, compact round video/switch controls, tactile press feedback, a pulsing REC timer, improved latest-media preview including a video play badge, and a matching polished Explorer toolbar.

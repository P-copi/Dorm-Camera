# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.12

V0.1.12 is the UI Polish + Quick Review build. It keeps the V0.1.11 camera, video, GPS, folder and Explorer behavior, while adding a cleaner rounded-control layout, prominent current-folder banner, latest-media thumbnail for one-tap review, an on-preview REC timer, and a visible tap-to-focus indicator.

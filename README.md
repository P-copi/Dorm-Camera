# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.10

V0.1.10 adds Explorer file tools with Share, Copy, Move, Rename, and Delete in one popup menu. Copy/Move support mixed photo/video multi-selection, destination folder selection or creation, confirmation before transfer, and automatic duplicate-safe naming.

# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.17

V0.1.17 is the Compact Preview + Save Banner + Video Thumbnail Polish build. It keeps the proven V0.1.16 video playback centering and compact REC indicator, reduces the Preview header so long file names stay on one ellipsized line, replaces the large Android save Toast after photo/video capture with a small animated in-app success banner, and adds a centered play badge to video thumbnails in Explorer so videos are easier to identify at a glance.

# Dorm Camera

Dorm Camera is a lightweight Android camera app focused on fast still capture, front/back video, GPS metadata, folder-based saving, and a simple in-app media Explorer.

Current development version: 0.1.18

V0.1.18 is the Branding Integration build. It keeps the proven V0.1.17 camera, Explorer, centered video playback, compact REC indicator, save banner, compact preview header, and video thumbnail polish unchanged, while adding the approved Dorm Camera gold/black camera-home app icon with the by.P signature, a short branded splash screen, Android 12+ native splash branding, and a soft fade transition into the camera.
